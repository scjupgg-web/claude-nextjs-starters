                    Claude Code 슬래시 명령어 완전 가이드

[사용법]
- 메시지 시작 부분에 / 입력 → 사용 가능한 명령어 목록 표시
- / + 문자 입력 → 필터링된 명령어 목록
- <arg> = 필수 인자, [arg] = 선택 인자
- 플랫폼, 요금제, 환경에 따라 일부 명령어 미지원 가능

================================================================================
1. 세션 관리
================================================================================

/clear [name]
  새로운 대화 시작 (프로젝트 메모리는 유지됨)
  [name]: 이전 대화에 라벨 지정

/resume [session]
  이전 대화 재개
  [session]: 세션 ID 또는 이름; 미지정시 선택 가능

/rename [name]
  현재 세션 이름 변경 (미지정시 자동 생성)

/branch [name]
  현재 지점에서 대화 분기 생성 (원본 대화 보존)

/fork <directive>
  백그라운드 서브에이전트로 작업 위임 (현재 대화 전체 상속)

/cd <path>
  세션의 작업 디렉토리 변경 (CLAUDE.md 자동 로드)

/add-dir <path>
  현재 세션에 추가 작업 디렉토리 접근 권한 부여

/color [color|default]
  세션 프롬프트 바 색상 설정
  가능한 색상: red, blue, green, yellow, purple, orange, pink, cyan

/exit | /quit
  CLI 종료 (백그라운드 세션은 계속 실행됨)

================================================================================
2. 모델 및 설정
================================================================================

/model [model]
  AI 모델 전환 및 기본값 설정
  예: opus, sonnet, fable; 미지정시 선택 화면 표시

/effort [level|auto]
  모델 추론 수준 조정
  레벨: low, medium, high, xhigh, max, ultracode

/fast [on|off]
  빠른 모드 토글 (응답 속도 향상, 비용 감소)

/advisor [model|off]
  조언자 도구 활성화/비활성화 (주요 결정 시 2번째 모델 조언 제공)

/config | /settings
  설정 인터페이스 열기 (테마, 모델, 출력 스타일 등)

/theme
  색상 테마 변경 (라이트/다크 모드, 색맹 테마, 커스텀 테마)

/tui [default|fullscreen]
  터미널 UI 렌더러 변경

================================================================================
3. 코드 검토 및 개선
================================================================================

/diff
  미커밋 변경사항과 턴별 diff 보기 (좌/우 화살표로 탐색)

/code-review [level] [--fix] [--comment] [target]
  현재 diff 검토 (버그, 정리 제안)
  level: low, medium, high, xhigh, max, ultra
  --fix: 발견된 문제 자동 적용
  --comment: PR 댓글로 작성
  ultra: 클라우드 멀티에이전트 심층 검토

/simplify [target]
  코드 정리 기회 검토 및 적용 (버그 탐지 없음, 4개 병렬 에이전트 실행)

/review [PR]
  PR 로컬 검토 (심층 검토는 /code-review ultra 권장)

/security-review
  현재 브랜치의 보안 취약점 분석

================================================================================
4. 컨텍스트 및 성능 관리
================================================================================

/context [all]
  현재 컨텍스트 사용량 시각화 (최적화 제안 및 용량 경고)

/compact [instructions]
  대화 요약으로 컨텍스트 해제 (포커스 지시사항 전달 가능)

/rewind | /checkpoint | /undo
  이전 지점으로 되돌리기 (대화와 코드 모두 되돌리기 가능)

/recap
  세션의 한 줄 요약 생성

/memory
  CLAUDE.md 편집 및 자동 메모리 관리 (활성화/비활성화, 항목 보기)

================================================================================
5. 권한 및 보안
================================================================================

/permissions | /allowed-tools
  도구 권한 관리 (Allow, Ask, Deny 규칙 설정)

/hooks
  Hook 설정 보기 (도구 이벤트의 Hook 설정 확인)

/sandbox
  샌드박스 모드 토글 (지원 플랫폼에서만 가능)

================================================================================
6. 병렬 작업 및 워크플로우
================================================================================

/agents
  서브에이전트 구성 관리 (백그라운드 작업 위임 설정)

/tasks | /bashes
  백그라운드 실행 작업 보기/관리 (실행 중인 모든 작업 표시)

/background [prompt] | /bg [prompt]
  현재 세션을 백그라운드 에이전트로 변환 (터미널 해제)

/batch <instruction>
  대규모 변경 병렬 분해 및 실행 (5-30개 독립 유닛으로 분해, 각각 PR 생성 가능)

/goal [condition|clear]
  조건이 충족될 때까지 작업 계속 (비대화형 모드에서 자동 실행)

/loop [interval] [prompt]
  반복 실행 (간격 생략시 자동 페이싱, 프롬프트 생략시 유지보수 점검)

/schedule [description] | /routines [description]
  클라우드 루틴 생성/관리 (크론 표현식 스케줄링)

================================================================================
7. 초기화 및 설정
================================================================================

/init
  CLAUDE.md 초기화 (CLAUDE_CODE_NEW_INIT=1: 대화형 플로우 활성화)

/mcp [reconnect <server>|enable|disable [<server>|all]]
  MCP 서버 연결 관리 (OAuth 인증 및 연결 상태 관리)

/keybindings
  키보드 단축키 파일 열기 (~/.claude/keybindings.json)

/terminal-setup
  터미널 키바인딩 설정 (Shift+Enter 등 단축키 구성)

/statusline [description]
  상태 바 설정 (미지정시 자동 구성)

8. 클라우드 및 웹 플랫폼
================================================================================

/teleport | /tp
  웹 세션을 터미널로 가져오기 (claude.ai 구독 필수)

/remote-control | /rc
  원격 장치에서 제어 가능하게 설정 (claude.ai에서 제어)

/desktop | /app
  Claude Code Desktop 앱에서 계속 (macOS/Windows + Claude 구독 필수)

/web-setup
  GitHub 계정 연결 (웹용, gh CLI 필수)

/remote-env
  클라우드 에이전트의 기본 실행 환경 선택

/ultraplan <prompt>
  브라우저에서 계획 수립 후 터미널에서 실행

/ultrareview [PR]
  클라우드 멀티에이전트 코드 검토 (별칭: /code-review ultra)

10. 스킬 및 플러그인
================================================================================

/skills
  사용 가능한 스킬 목록 보기
  단축키: t = 토큰 수 정렬, Space = 스킬 숨기기

/plugin [subcommand]
  플러그인 관리
  서브명령: list, install, enable, disable

/reload-skills
  스킬 디렉토리 재스캔 (세션 중 추가/변경된 스킬 로드)

/reload-plugins [--force]
  활성 플러그인 재로드 (대기 중인 변경사항 적용)

11. 솔루션 작업 명령어
================================================================================

/run
  프로젝트 앱 실행 및 드라이브 (실행 중인 앱에서 변경사항 직접 확인)

/verify
  코드 변경 확인 (테스트/타입 체크 대신 직접 관찰)

/plan [description]
  계획 모드 직접 진입 (선택사항: 즉시 작업 시작)

/btw <question>
  빠른 사이드 질문 (대화 기록에 추가되지 않음)

12. 진단 및 지원
================================================================================

/doctor
  설치 및 설정 진단 (문제 상태 표시, f로 자동 수정)

/debug [description]
  디버그 로깅 활성화 (문제 설명으로 분석 집중)

/feedback [report] | /bug [report] | /share [report]
  버그 신고/피드백 제출 (세션 컨텍스트 자동 포함)

/export [filename]
  대화를 텍스트로 내보내기 (파일명 지정시 직접 저장)

/copy [N]
  마지막 응답을 클립보드에 복사 (N: 몇 번째 최근 응답)

/heapdump
  메모리 사용량 진단 (~/Desktop에 스냅샷 저장)

16. MCP 프롬프트 명령어
================================================================================

형식: /mcp__<server>__<prompt>
  MCP 서버가 expose한 프롬프트를 명령어로 사용
  예: /mcp__github__search-issues
  연결된 MCP 서버에서 동적으로 발견됨

자주 사용하는 워크플로우
================================================================================

[프로젝트 시작]
  /init → /memory → /mcp → /agents

[코드 작업]
  /plan → 개발 → /code-review → /security-review

[병렬 작업]
  /batch 또는 /fork + /agents

[성능 최적화]
  /context → /compact
