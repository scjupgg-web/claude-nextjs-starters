현재 코드베이스를 분석하여 `docs/ROADMAP.md`의 체크박스를 실제 구현 상태에 맞게 업데이트하세요.

## 수행 절차

### 1단계 — ROADMAP 파악
`docs/ROADMAP.md`를 읽어 `- [ ]` 체크박스가 있는 모든 태스크 목록을 파악합니다.

### 2단계 — 구현 상태 검증
각 태스크에 명시된 파일 경로, API, 컴포넌트가 실제로 존재하는지 코드베이스에서 확인합니다.

검증 기준:
- **파일 존재 여부**: 태스크에 언급된 파일 경로(예: `app/invoice/[id]/page.tsx`)가 실제로 존재하는가
- **핵심 로직 구현 여부**: 파일이 존재하더라도 TODO 주석만 있거나 stub이면 미완으로 간주
- **의존성 설치 여부**: `package.json`에 필요한 패키지가 포함되어 있는가
- **환경 설정 파일**: `.env.example` 등 문서화 파일 존재 여부

### 3단계 — 체크박스 업데이트
검증 결과에 따라 `docs/ROADMAP.md`에서:
- 구현 완료된 태스크: `- [ ]` → `- [x]`
- 미완이거나 확인 불가한 태스크: `- [ ]` 유지 (절대 미완을 완료로 표시하지 않음)
- 이미 `- [x]`인 항목: 실제로 구현이 제거된 경우에만 `- [ ]`로 되돌림, 아니면 유지

### 4단계 — 결과 보고
변경된 항목을 아래 형식으로 보고합니다:

```
## 업데이트 결과

### ✅ 새로 완료 처리된 태스크
- F001 — [태스크명]: [판단 근거 (파일 경로 등)]

### ⏳ 미완으로 유지된 태스크
- F002 — [태스크명]: [이유]

### 📊 Phase별 진행률
- Phase 1: X/Y 완료
- Phase 2: X/Y 완료
```

## 주의사항

- **과도한 체크 금지**: 파일이 존재해도 실제 로직이 없으면 미완으로 표시
- **Playwright 테스트 태스크**: 실제 테스트 실행 없이는 완료 처리 불가 — 항상 미완 유지
- **배포 관련 태스크** (Vercel 배포 검증 등): 코드만으로 확인 불가 — 항상 미완 유지
- ROADMAP 파일 외 다른 파일은 수정하지 않음
